# MAIA PoC Reports

This repository stores Markdown reports generated by the MAIA Settlement Mailbox PoC workflows.

## Structure

```text
reports/
  YYYY-MM-DD/
    processed/
      *_settlement_report.md
    human_review/
      *_human_review_report.md
    no_action/
      *_no_action_report.md
```

## Report types

- `processed` — standard settlement cases processed through HOST lookup and reconciliation.
- `human_review` — cases requiring analyst review because of low confidence, ambiguity, missing data, failed attachment parsing, or validation issues.
- `no_action` — emails classified as not relevant to settlement processing.

## Report contents

Each report may include:

- source email metadata;
- classification and confidence score;
- extracted trade facts;
- evidence snippets;
- attachment extraction status;
- HOST lookup result;
- field-by-field reconciliation;
- discrepancy flags;
- recommended next action;
- draft analyst response;
- audit trail and warnings.

## Notes

Reports are generated automatically by CodeMie workflows for PoC purposes.

Do not treat reports as final business decisions without analyst validation.
